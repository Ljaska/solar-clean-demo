# SolarSpark

A production-ready, mobile-first solar panel cleaning website built with semantic HTML5, modern CSS and vanilla JavaScript.

## Run locally

Open `index.html` directly in a browser. No framework, build step or local server is required.

## Production checklist

Before launch, replace the temporary SolarSpark company details, domain, address, telephone number, email, social links and customer statements with verified client information. Connect the quote form submission handler to the chosen backend or CRM endpoint. The current form includes complete client-side validation and a backend-ready success state.

## Structure

- `index.html` — complete landing page and structured data
- `privacy.html`, `terms.html` — supporting legal pages
- `css/` — design system, responsive rules and motion
- `js/` — navigation, counters, form, lightbox, comparison, testimonials and FAQ
- `images/` — local WebP photography
- `favicon/` — browser and app icons
- `robots.txt`, `sitemap.xml`, `manifest.webmanifest` — discovery and install metadata

## Accessibility and performance

The site uses semantic landmarks, keyboard-accessible interactive controls, visible focus states, reduced-motion support, intrinsic image dimensions, responsive image sources and lazy loading below the fold.
