# Sunclean Latvia Website

Official website for **SIA Sunclean Latvia**.

## Overview

This repository contains the source code of the official Sunclean Latvia website.

Services include:

- Solar panel cleaning
- Roof cleaning
- Facade cleaning
- Gutter cleaning

The website is fully responsive and available in:

- Latvian
- English
- Russian

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks or build tools are required.

## Deployment

The website is published using GitHub Pages.
